# **App Name**: Photo Poet

## Core Features:

- Image Upload: Upload an image to inspire the AI poem generation.
- Poem Generation: Generate a poem based on the content and mood of the uploaded image.
- Poem Display: Display the generated poem alongside the uploaded image.
- Poem Refinement: The AI tool helps to refine the generated poem by offering different tones or styles.

## Style Guidelines:

- Primary color: Neutral grays for readability and focus on the image and poem.
- Accent: Teal (#4DB6AC) to highlight interactive elements and calls to action.
- Serif fonts for poem display, enhancing readability and a classic feel. Optimized for mobile viewing.
- Clean, centered layout optimized for mobile screens to emphasize the image and poem. Responsive design for various screen sizes.
- A hidden side navigation bar that appears when a button is clicked, offering additional options in a mobile-friendly manner.
- Subtle fade-in effects for poem text and image transitions. Smooth transitions for a polished, elegant feel.

## Original User Request:
An app that generates poems from photos
